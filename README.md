# RF Mapping with Drone Swarm

The working prototype is in [`rf_mapping_project`](rf_mapping_project/README.md).
It is a probabilistic RF-assisted mapping experiment, not full SLAM and not a
replacement for camera/IMU/VIO/SfM collision geometry. The project README has
the complete Windows/POSIX setup, calibration, survey, inference, validation,
and safety workflow.
