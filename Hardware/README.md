# Hardware

Physical system design and component records belong here: drone mechanical
design, electrical schematics, power distribution, BOMs, sensor hardware,
base-station hardware, and docking hardware.

No CAD, PCB, schematic, or BOM files are present yet. Add the relevant
Drone, Sensors, Base_Station, or Docking_Station subdirectory with its first
design artifact. Record the exact board and antenna before specifying payload
connections.

See the [system architecture](../Docs/Architecture/system_overview.md).
ESP32 firmware lives in [ESP32_Code](../ESP32_Code/); FPGA sources belong in
[FPGA](../FPGA/).
